# Segurity-Home-Alarma-ESP01-ESP32-Telegram
Sistema de alarma para ESP-01/ESP32 (3.3V) con activación por corte y restauración de alimentación. Ideal para protección perimetral con reed switches, PIR o sensores. Al restaurar los 3.3V, el ESP-01 dispara alertas por Telegram (grupo + administrador). Incluye portal web completo de configuración, modo desplegado/replegado y bajo consumo.
